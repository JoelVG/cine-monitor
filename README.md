# cine-monitor
Movie monitor for [Skybox](https://skyboxcinemas.com.bo/) and [Prime](https://primecinemas.com.bo/) cinemas.

This project scrapes movie information from the cinema websites and sends notifications via Telegram.

**Features:**
- Scrapes movie titles from Skybox and Prime Cinemas.
- Sends new movie notifications to subscribed users via Telegram.

**How it works:**
Users interact with the Telegram bot using available commands.
The bot monitors the cinema websites for new movie releases and notifies subscribed users.

# Commands
Available commands for interacting with the bot:
- `add`: Subscribe to movie notifications.
- `remove`: Unsubscribe from movie notifications.

# Setup

**Prerequisites:**
- Python 3.7+
- Docker (optional)

**Installation:**
1. Clone the repository:
   ```bash
   git clone <repository_url>
   cd cine-monitor
   ```
2. Install dependencies, including Playwright:
   ```bash
   pip install -r requirements.txt
   # Install Playwright browsers
   playwright install
   ```

# Docker
To build and run the project using Docker:
```bash
docker build -t cine-monitor .
docker run -d --name cine-monitor-container cine-monitor
docker exec -it cine-monitor-container /bin/bash
```
> Files generated by `monitor.py` are saved in `./root/`.

# Crontab
To schedule the `monitor.py` script to run periodically using crontab:
```bash
crontab -l # list active cron jobs
crontab -e # edit the cron job file
```
Add a line similar to the following to run the monitor script every hour (adjust the schedule as needed):
```crontab
0 * * * * /usr/bin/python /path/to/your/project/monitor.py
```
